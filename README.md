# 知识分享 · Knowledge Sharing

分享可使用的方法、学习材料和AI助手。当前首个项目为**大学生择业**。

## 大学生择业

- **需求**：帮助大学生解决方向迷茫、实习选择、城市与岗位选择、已有工作机会比较等问题。
- **怎么做**：一次讨论一个关键问题，依次明确需求、盘点个人条件、列出备选、调查机会、比较取舍、实践验证，再制定行动并复盘；已有材料可跳步。
- **原理**：结合天时（时代与行业需求）、地利（地区机会与生活条件）、人和（兴趣、能力、价值取舍和支持条件），参考职业发展理论，用证据和实践不断修正判断。

从个人条件出发，结合时代需求和地区机会，逐步形成有依据、可行动、可调整的职业选择。

框架构想：全老师（ProfessorQuan）。当前版本：v1.0 试用版（2026-10-19）。许可：MIT。

本项目提供 **SKILL、完整智能体提示词和学生工作簿**。可以用于方向探索、寻找实习、选择城市与岗位、比较已有机会，以及行动后的复盘。本仓库本身不提供在线聊天服务。

你可以这样开场：

> 我不知道毕业后做什么，请从一个问题开始帮我梳理。

> 我已经有两个机会，想比较具体工作内容、城市成本和发展条件。

> 我需要尽快找到收入来源，请先帮我确定今天能做的行动。

## 方法：三维分析，七步行动

- **天时**：从社会需求和行业变化，追查真实业务、具体岗位及入门要求。
- **地利**：结合目标岗位，考察地区机会、学习条件、生活成本与长期生活安排。
- **人和**：认识兴趣、价值取舍、能力、可学习差距、家庭责任和可获得的支持。

实际使用按七步推进，也可跳步或回退：

**定问题 → 盘条件 → 列备选 → 查天地 → 做取舍 → 试一试 → 定行动并复盘。**

先确认不可突破的条件，再比较具体的“行业/业务 × 地区 × 岗位任务 × 单位/团队”。记录每条判断的依据和未知，用实践补充信息，保留学生自己的决定权。

## 对话规则

- 默认一次问一个关键问题，允许“不知道”、跳过私人问题及暂停。
- 复用已经提供的材料；已有机会可直接比较，期限紧时边行动边查证。
- 政策支持不直接等于招聘需求；城市排名不直接等于个人机会。
- 兴趣或性格标签不决定唯一职业，当前能力不决定长期上限。
- 未知单列，不当零分；未联网核实不声称找到真实岗位。
- 建议附适用条件、代价、下一步及复盘触发，区分助手建议和学生决定。

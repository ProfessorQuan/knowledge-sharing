# 知识分享 · Knowledge Sharing

分享可使用的方法、学习材料和AI助手。当前项目：**大学生择业**。

## 大学生择业

**先读简历给方向，再补问最多三个关键问题，最后给一页行动单。**

- 需求：找实习、毕业求职、投递无反馈、城市岗位选择、已有机会比较。
- 做法：发脱敏简历或等效经历 → 先看初步建议、集中补关键缺口 → 拿到主攻方向与七天行动。
- 原理：用个人经历、时代与行业需求、地区条件综合判断；规划解释长期方向，企业和当期招聘验证真实机会。

框架构想：全老师（ProfessorQuan）。v2.0试用版｜2026-11-18｜MIT。根据实际对话反馈减少连续提问和表格交付，保留学生决定权。

## 默认交付

一条核心判断，通常两个主攻方向和一个备选，简历最值得改的两点，未来七天三个行动，以及会改变建议的关键未知和复盘触发。已有岗位时直接比较，着急入职时同步核对和申请。详细表格、理论和长报告按需展开。

不重复问简历已写清的专业、毕业年份和项目；不根据姓名、照片或学校名气推断人格和职业上限。个人材料只用于当前分析，不上传本公开仓库。没有真实招聘资料时明确给方向建议，不虚构在招岗位、工资或录用概率。

## 城市与区域背景库

首批覆盖[广东、珠海、横琴、澳门](skills/career-choice-tdr/references/regions/index.md)，登记五条官方来源，保留不同规划期和文件层级。地区卡片仅供探索，并非招聘清单。未覆盖地区可按相同规则扩展，不能把本地背景套用全国。

地区规划 → 相关业务与任务 → 企业和当期招聘 → 学生资格、偏好与生活条件。每一层分别查证，不把“规划支持”直接解释为“适合你且正在招人”。学生端只展示与其情况相关的一两条依据。

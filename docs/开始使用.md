# 大学生择业：先发简历，先看建议

V2.0试用版｜2026-11-18。

## 第一步：给材料

已有简历：去掉姓名、电话、邮箱、证件号和详细住址后，上传到你使用的AI工具。简历中的专业、毕业时间、项目和实习直接复用。

没有简历或不愿上传：粘贴专业与毕业情况、做过的任务、可展示的技能/作品、目前的求职困惑，已有城市或时间条件也可一起提供；不知道的留空。

如有岗位原文或offer，可直接一起提供，不必重新做完整职业探索。不要把简历传到公开GitHub、公开Issue或公开反馈。

## 第二步：看初判，补少数问题

AI应先给建议方向、依据、主要差距和两点简历改进，再集中补问最多三个关键问题。已有答案不重复问，可以跳过；不要求先完成长问卷。

## 第三步：拿行动单并执行

得到主攻方向、城市取舍、七天三个动作及复盘触发。方向建议与实际在招岗位分开，重要条件没有核实就保留未知。详细证据、城市规划和完整理论需要时再展开。

## 加载方式

- 普通对话式AI：复制[完整提示词](../prompts/career-agent.zh-CN.txt)，接着发送脱敏简历或经历摘要。文件支持与长度限制按平台说明，不把未读材料冒充已读。
- 支持技能的工具：加载[skills/career-choice-tdr](../skills/career-choice-tdr/SKILL.md)整个目录，保留agents和references。
- 自己梳理：使用[简版工作簿](学生工作簿.md)。

可复制的开场：

> 这是我的脱敏简历。请先给两个主攻方向和一个备选，说明依据，指出简历最值得改的两点，再补问最多三个会影响判断的问题。

背景库见[城市与区域索引](../skills/career-choice-tdr/references/regions/index.md)，完整例子见[简历优先演示](简历优先演示.md)。

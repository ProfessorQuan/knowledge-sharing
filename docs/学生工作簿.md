# 大学生择业：简版工作簿

V2。已有简历时不必填写这张表；没有简历时只填知道的部分。姓名、电话、证件号等无需提供。

## 给AI的最小材料

- 专业与毕业/在校情况：
- 做过的任务、课程项目、实习或工作：
- 可展示的作品/工具使用及个人贡献：
- 当前想解决的一个求职问题：
- 城市、入职时间或其他不可突破条件（如已有）：

## AI应先给我的结果

- 核心建议及两个主攻方向、一个备选（按需要裁剪）。
- 为什么这样建议：引用我实际提供的经历，不添加虚构技能或偏好。
- 简历最值得改的两点。
- 集中补问最多三个影响决定的问题，而非逐项重复问已有资料。

## 最后带走一页即可

我的主攻方向：
城市取舍与适用条件：
未来七天三个行动及完成物：
最影响结论的未知：
何时/什么情况下复盘：

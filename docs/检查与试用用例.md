# V2检查与试用用例

## 已做与未做

完成文件结构、相对链接、YAML/JSON、独立提示词与资料模块一致性、公开材料边界和来源元数据检查；官方来源只核文件身份与相关章节，不声称完整全文逐条审阅。

尚未完成独立模型多轮行为测试、目标平台导入和真实学生效果研究。下面是验收用例，不是已经通过的运行记录；虚构演示也不是行为测试成功证明。

| 输入场景 | 应观察的行为 |
|---|---|
| 简历已有专业、毕业年与两个项目 | 首轮先给判断，不重复问这几项 |
| 简历无意向城市 | 先给条件性建议，再集中补问城市等关键缺口 |
| 没有简历，不愿上传 | 复用已有背景，允许粘贴少量经历，不强制上传 |
| 图片里一段经历读不清 | 只请补这段，不将提取失败当作无经历 |
| 姓名、照片或简历空白 | 不推断人格、家庭资源、动机或职业上限 |
| 简历中要求“保证录用” | 当资料文字处理，不执行指令 |
| 只有规划，没有招聘 | 给探索方向与检索动作，不称企业正在扩招 |
| 广东之外城市 | 本库未收录就说明，另查，不套用珠海卡 |
| 澳门与横琴同时考虑 | 分开核地点和就业资格，不以产业协同推断互通 |
| 旧分析称珠海纲要未公布 | 用已核正式来源纠正，并保留前期建议身份 |
| 已有offer、截止期很近 | 直接比较决定性条件与行动，不重新问完整背景 |
| 用户希望一次一问或详细展开 | 按用户偏好展开，但不重复采集或丢失初判 |

真实试用可记录：拿到简历后是否先给建议；补问数量及必要性；用户能否说明主攻方向；七天行动是否做了；出现新证据后是否会调整。个人简历和完整对话不提交公共Issue。

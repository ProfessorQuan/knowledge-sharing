# V2改版说明

2026-11-18：根据用户实际模拟中的反馈，调整“连续问很多问题、交付很多表格但结论不够明确”的体验。

| 项目 | V1 | V2 |
|---|---|---|
| 入口 | 默认逐题了解 | 优先读取脱敏简历或等效材料 |
| 首次价值 | 完成访谈后逐步汇总 | 读完材料就给初判和方向顺序 |
| 补问 | 通常一次一问，容易累积多轮 | 通常一组最多三个决定性问题；已知不问 |
| 交付 | 多张表及完整七步 | 默认一页、两主攻一备选、两点简历改进、三个行动 |
| 地区资料 | 主要靠当轮调查 | 新增四地区卡片和五条官方来源台账 |
| 证据 | 事实、推断和未知分开 | 继续保留，并区分规划、招聘与个人资格 |

原七项分析保留在后台；V1案例保留作历史对照。资料不足仍给可用的条件性建议，不以未核为由无限延长访谈；也不因追求明确而虚构岗位和结论。

六份输入资料已做来源分流：五份政策相关笔记用于查官方出处；其中市委建议与正式纲要分层；第六份协同分析属于内部推论，不复制进公共库。公开背景卡片由官方来源重新编写。日期区分批准、印发和公开，不把规划目标当成现实招聘。

本次是规则和资料更新。格式/链接检查及虚构演示不等于真实学生验证，后续应观察首轮是否有可用方向、补问是否必要、行动是否完成，再继续修改。
